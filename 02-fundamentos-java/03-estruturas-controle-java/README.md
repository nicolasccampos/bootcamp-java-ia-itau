# Estruturas de Controle em Java

Essas são minhas anotações da aula **Estruturas de Controle em Java**.

Aqui eu vi as estruturas que mais aparecem quando a gente precisa tomar decisões ou repetir coisas no código.

## O que foi estudado

- `if`, `else` e `else if`
- `switch case`
- `for`
- `while` e `do while`
- exercícios práticos

---

## if / else / else if

Usei essas estruturas quando precisava comparar valores e seguir caminhos diferentes no código.

O que eu anotei aqui:

- `if` serve quando quero testar uma condição
- `else` serve quando a condição principal não acontece
- `else if` serve quando tenho mais de uma possibilidade

Também trabalhei com:

- operadores de comparação: `>`, `<`, `>=`, `<=`, `==`, `!=`
- operadores lógicos: `&&`, `||`, `!`

Exemplos que ficaram na cabeça:
- maior ou menor de idade
- nota de aprovação
- validação de entrada

---

## switch case

Usei `switch` quando tinha uma escolha entre opções fixas.

Ele ajuda bastante quando a gente tem casos como:

- `par` e `impar`
- opções de menu
- dias da semana
- letras ou valores exatos

O principal aqui foi lembrar:

- `case` para cada opção
- `break` para não continuar caindo nos próximos casos
- `default` para quando a entrada não faz sentido

---

## for

O `for` foi útil quando eu sabia exatamente quantas vezes queria repetir alguma coisa.

A estrutura básica que eu usei foi:

- início
- condição
- passo

Exemplos que fiz com ele:
- tabuada
- contagem decrescente
- listar números pares e ímpares dentro de um intervalo

---

## while e do while

Essas duas estruturas eu usei quando a repetição dependia de uma condição.

### while
- testa a condição antes de entrar no bloco
- se a condição já começar falsa, pode nem executar

### do while
- executa pelo menos uma vez
- depois testa a condição

Aqui eu também precisei prestar atenção em:
- atualizar a variável de controle
- evitar loop infinito
- saber quando parar o programa

---

## O que eu aprendi de verdade nessa aula

- usar `if` para decidir caminhos no código
- usar `switch` quando a escolha é entre opções mais diretas
- usar `for` para repetir com contador
- usar `while` quando quero repetir enquanto uma condição continuar válida
- usar `do while` quando preciso executar pelo menos uma vez
- validar entrada do usuário antes de seguir com a lógica
- usar `return` quando quero encerrar a execução
