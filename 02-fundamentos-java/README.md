# Módulo 2 – Fundamentos de Java

Este módulo reúne os conteúdos de Java básico estudados no bootcamp **Itaú + DIO**, desde a introdução ao ambiente até as primeiras estruturas de controle e exercícios práticos.

## Estrutura do módulo

- [`01-introducao-ambiente-java/`](01-introducao-ambiente-java)  
  Introdução ao Java, instalação do JDK, IntelliJ IDEA, Hello World, primeiro programa, debug e entrada de dados.

- [`02-fundamentos-linguagem-java/`](02-fundamentos-linguagem-java)  
  Fundamentos da linguagem: tipos primitivos, variáveis, operadores, `Scanner`, bitwise e exercícios de cálculo.

- [`03-estruturas-controle-java/`](03-estruturas-controle-java)  
  Estruturas de decisão e repetição: `if`, `switch`, `for`, `while` e `do while`, com exercícios práticos.

Cada pasta tem o seu próprio `README.md` com anotações, exemplos e links para os arquivos correspondentes.
