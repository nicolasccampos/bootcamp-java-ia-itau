Neste módulo do Bootcamp Itaú - Java com Inteligência Artificial, estudei conceitos fundamentais relacionados à evolução e ao funcionamento da Inteligência Artificial moderna.

## Conteúdos abordados

Durante o módulo, tive contato com conceitos relacionados a:

- Inteligência Artificial;
- Machine Learning;
- Large Language Models (LLMs);
- Inteligência Artificial Generativa;
- Agentes de IA.

## Machine Learning

Machine Learning é uma área da Inteligência Artificial que permite que sistemas identifiquem padrões a partir de dados e utilizem esses padrões para realizar previsões, classificações ou outras tarefas.

Esse conceito é uma das bases para diversas aplicações modernas de IA.

## Large Language Models (LLMs)

Os LLMs são modelos treinados com grandes quantidades de dados textuais e capazes de trabalhar com linguagem natural.

Eles estão por trás de diversas ferramentas atuais capazes de interpretar solicitações e gerar conteúdos como textos e códigos.

## IA Generativa

A Inteligência Artificial Generativa utiliza modelos capazes de produzir novos conteúdos a partir das informações e instruções fornecidas pelo usuário.

Entre suas aplicações estão a geração de:

- textos;
- código;
- imagens;
- resumos;
- ideias e conteúdos.

## Agentes de IA

Também tive contato com o conceito de agentes de IA, sistemas que podem utilizar modelos de Inteligência Artificial em conjunto com ferramentas e instruções para realizar tarefas e buscar determinados objetivos.

## Relação entre os conceitos

Um dos pontos importantes deste módulo foi compreender melhor como diferentes conceitos presentes na IA moderna se relacionam.

Uma forma simples de entender, pelo menos para mim:

**Dados → Machine Learning → Modelos → IA Generativa → Aplicações e Agentes**

Cada conceito possui suas particularidades, mas juntos ajudam a compreender diversas ferramentas de Inteligência Artificial utilizadas atualmente.

## Conclusão

Este módulo me serviu como uma introdução aos principais conceitos por trás da IA moderna e criou uma base para compreender melhor as tecnologias e aplicações que serão exploradas durante o bootcamp.
