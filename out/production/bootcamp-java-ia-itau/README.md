# Primeiro Programa Java

Exercício prático do **Módulo 2** do Bootcamp Java & IA (Itaú + DIO), criado para reforçar a estrutura inicial de um programa Java.

## Objetivo
Criar um segundo exemplo simples de execução em Java, separado do exercício `HelloWorld`, para manter a organização por atividade.

## Código

```java
public class PrimeiroPrograma {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

## Estrutura usada

```text
first-program-java/
├── PrimeiroPrograma.java
└── README.md
```

## Aprendizados
- Organização de exercícios em pastas separadas
- Relação entre nome do arquivo e nome da classe
- Uso do método `main` como ponto de entrada
- Execução de um programa Java simples

## Observação
Mesmo sendo um exercício inicial, a prática de separar cada atividade em sua própria pasta ajuda a manter o repositório limpo e fácil de navegar.
