# Hello World

Exercício inicial criado durante os estudos do **Módulo 2** do Bootcamp Java & IA (Itaú + DIO).

## Objetivo
Praticar a estrutura básica de um programa Java e validar a organização dos arquivos no projeto.

## Código

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

## O que esse exercício mostrou
- criação de uma classe Java;
- uso do método `main` como ponto de entrada;
- impressão de uma mensagem no console;
- organização inicial de arquivos no repositório.

## Observação
Este exercício foi usado apenas para entender a estrutura inicial do projeto.  
O primeiro programa oficial da aula será adicionado em outra pasta.
